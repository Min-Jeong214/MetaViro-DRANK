# Research data, copyright and release policy

- The Git repository contains **source code and general manuals**, not reference databases, raw sequencing data or study-specific analysis results.
- Do not publish unpublished research data, credentials, local configuration paths, external database binaries or predicted structures without permission.
- `.gitignore` prevents many additions but **does not erase files from existing Git history**. Review tracked paths and history before making the repository public.
- Study-specific validation and benchmark materials should be documented in the manuscript/supplement and associated Zenodo repository record, subject to scientific and institutional approval.
